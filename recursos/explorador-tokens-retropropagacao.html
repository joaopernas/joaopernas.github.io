02 · Aprendizagem

O erro regressa para melhorar a previsão

Na retropropagação, o modelo calcula o erro à saída, propaga essa informação para trás e ajusta os pesos das ligações.

Rede neuronal simplificada

Representação simplificada para fins pedagógicos; uma rede real pode incluir milhões ou milhares de milhões de parâmetros.

Ciclo de aprendizagem

1Propagação diretaOs dados atravessam a rede e originam uma previsão.
2Cálculo do erroA previsão é comparada com o resultado esperado.
3RetropropagaçãoO contributo de cada ligação para o erro é calculado.
4Ajuste dos pesosPequenas correções reduzem o erro na tentativa seguinte.

03 · Conceitos essenciais

Duas ideias, um mesmo processo

Tokens

São unidades numéricas que representam texto. Uma palavra pode corresponder a um token, a vários tokens ou partilhar partes com outras palavras.

Pesos

Determinam a influência de cada ligação. Aprender significa ajustar estes valores para produzir resultados progressivamente mais adequados.

Retropropagação

É o mecanismo que distribui o erro pelas camadas anteriores e indica a direção dos ajustes a realizar durante o treino.
