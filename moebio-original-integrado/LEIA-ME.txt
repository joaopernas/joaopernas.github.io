VISUALIZADOR DE MODELOS DE LINGUAGEM

Entrada publicável:
  visualizador-modelos-linguagem.html

Publicação no GitHub Pages:
  1. Copiar a estrutura completa, sem alterar os caminhos relativos.
  2. Manter visualizador-modelos-linguagem.html no mesmo nível das pastas data, libraries, mind e Pulse_And_Tiles.
  3. Abrir através de um servidor HTTP/HTTPS. O carregamento dos JSON não funciona corretamente se o ficheiro for aberto diretamente por file://.
  4. A ligação de regresso aponta para inteligencia-artificial.html no mesmo diretório.

Conjuntos visíveis em Português de Portugal:
  - data/inteligencia_e_completo.json — conjunto inicial
  - data/inteligencia_e_baseline.json — alternativa
  - data/inteligencia_e.json — conjunto original

Arquitetura integrada:
  - mind/Build.js — construção da árvore a partir dos dados reais
  - mind/Process.js — PCA dos embeddings reais
  - Pulse_And_Tiles/Tiles/Tree — árvore interativa original em iframe
  - libraries/PCA.js e libraries/numeric-1.2.6.min.js — cálculo PCA
  - mind/classes/HtmlArea.js e Help.pt.txt — ajuda adaptada
  - integracao.js — ligação entre a interface publicada e os módulos fornecidos

A fonte Roboto não é necessária. A interface usa:
Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Arial, sans-serif.
